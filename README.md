# Flaggenspiele

Ein Browserspiel mit drei Spielen:

- **Flaggen erkennen** – welche Flagge gehört zu welchem Land?
- **Flaggen ausmalen** – male die Flagge in den richtigen Farben aus.
- **Flaggen auf der Karte** – ziehe die Flagge auf das richtige Land.

Richtige Antworten werden mit einem Lametta-Feuerwerk gefeiert, falsche mit einem traurigen Emoji 😢.

Läuft als installierbare Web-App (PWA) über GitHub Pages.
